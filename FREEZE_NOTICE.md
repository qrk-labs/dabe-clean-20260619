# DABE Development Freeze Notice

**Status:** Frozen after preprint publication.  
**Effective date:** 2026-06-23.  
**Published DOI:** https://doi.org/10.5281/zenodo.20797432

This repository is frozen as the publication artifact for the DABE preprint. Agents and contributors should treat the current code, configs, paper sources, experiment logs, and lightweight artifacts as archival unless the user explicitly says to unfreeze development.

During the freeze:

- Do not launch new experiments, Modal jobs, GPU runs, sweeps, or architecture work.
- Do not alter paper claims, experiment records, or reported metrics except for explicit errata/correction work.
- Do not rewrite published paper sources except for metadata, citation, DOI, formatting, or errata tasks requested by the user.
- Prefer preservation tasks: README updates, DOI/citation metadata, artifact hygiene, website/blog adaptation, and reproducibility notes.
- If a requested change could affect scientific claims, pause and ask for explicit confirmation before editing.
