# Experimental Setup

## Dataset And Token Basis

All main tokenizer-autoencoder experiments use TinyStories with `4096` training samples and `512` validation samples in streaming mode. Text is converted to GPT-2 token IDs, and each training example is chunked into fixed 64-token slabs. This keeps the evaluation focused on learned chunk reconstruction rather than on changing the underlying text preprocessing pipeline.

## Training Protocol

The main runs use a Modal T4 GPU, `bf16-mixed` precision, batch size `32`, `12000` maximum training steps, validation every `300` steps, and checkpointing every `2000` train steps. Each experiment logs its configuration, run ID, launch contract, and final summary into `research/experiment_log.md` and `experiments/modal_downloads/`.

## Metrics

We report token accuracy, top-5 and top-10 token accuracy, exact 16-token block accuracy, exact 64-token chunk accuracy, mean chunk deviation, p90 chunk deviation, observed effective bits/token, active lookup K, and bit density. Chunk deviation is the primary distortion metric for comparing reconstructions that are close but not exactly identical.

## Runtime And Compute Accounting

Each main optimizer step processes `32 * 64 = 2048` GPT-2 tokens. The fixed-rate EXP-093 run logged an ETA sample of `14.34` steps/s, or about `29,368` tokens/s. The cost-aware EXP-092 sweep logged `7.80` steps/s on its first child, or about `15,974` tokens/s. This suggests roughly a `1.8x` training-throughput cost for sparse repair relative to the matched no-lookup baseline on the logged T4 runs.

| EXP-093 fixed-rate no lookup | `1280` | `0` | `0.00` | `0.00` | `20.000` |

EXP-094 adds a measured decode-profile pass on the EXP-087 checkpoint: `1351` validation chunks in `6.42` seconds, or `210.33` chunks/s and `13,461` tokens/s. CUDA peak allocated/reserved memory was `2031.74`/`2152.00` MiB.

## Baselines And Ablations

The main fixed-rate comparator is EXP-093, a no-lookup hierarchical-local decoder at `20.0` bits/token. The main DABE cost-aware point is EXP-092 at `20.06207` observed bits/token. EXP-087 is the quality anchor. EXP-088, EXP-089, and EXP-090 test variable token-window alternatives. EXP-077 through EXP-087 provide the adaptive-budget development path.

## Figure Generation

All paper figures are generated by `scripts/build_paper_figures.py`. The script normalizes experiment artifacts into `research/paper_drafts/figures/figure_data.json`, renders SVG directly with the Python standard library, and converts each figure to PDF and PNG with `rsvg-convert`. This avoids notebook-only state and makes the figure pipeline reproducible from checked-in artifacts.
